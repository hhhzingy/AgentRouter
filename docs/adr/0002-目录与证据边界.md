# ADR 0002：目录、安装与证据边界

状态：已选择，2026-09-09。

唯一开发根为 E:\AgentRouter。apps 为应用入口，packages 为模块，native 为 Windows helper，tools 为复现工具，tests 为测试，fixtures 为固定样本，evidence 为脱敏执行证据，docs/adr 为架构决策。

开发缓存、下载、临时文件及探针运行数据统一放 .local；如需 worktree，只可放 .worktrees。两者不上传。pi 私有安装位于 .local/pi，不升级已有 Codex/Kimi，不修改全局 PATH。

开发探针仅使用无账号、无秘密的隔离配置。正式产品的凭据与控制数据必须在工作区外的受限用户数据目录；这与项目内开发临时目录不同，不能把测试目录直接作为生产安全边界。

每阶段报告 implemented/tested/blocked/known_risk。NOT_RUN 不等于 FAIL，官方资料不等于现场通过；依赖 Gate 未过时，不宣告后续阶段完成。保存原始开发包及其 manifest，不删除用户内容。

## 2026-09-09 用户修订

用户明确要求 pi 安装到 Windows 用户目录。改为 `%APPDATA%/npm` 的用户级安装，不修改系统 PATH；原先项目内的安装不再作为执行入口。开发缓存、探针无账号配置和临时文件仍放项目 .local 内。原先无账号测试安装副本暂保留，避免自动删除；与新版锁记录区分。
