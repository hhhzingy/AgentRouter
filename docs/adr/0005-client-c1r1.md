# ADR 0005：C1R1 产品合同与历史边界

状态：已实现，待复核。前序：ADR 0004；基线 18c259c。

产品新增协作组重构、AI 角色编排、角色章程与模型目录。采用独立 C1R1 Schema / 生成类型 / freeze，保留 C1 并协商闭合投影。21 个新方法通过同一控制租约、幂等键、全局 revision 和 scope 管理。

Space 控制未来通信与规则，Workspace 控制工作目录资源；二者分离。重构归档旧组、创建新组，角色 ID 稳定；历史消息与任务保留原组和规则。MOVE 用关联后继任务实现，避免改写历史外键。结果默认目标跨组时要求显式选择。旧会话上下文不可假设遗忘。

Role Plan 的权限只是请求；Core Mock 求交后发布新章程。章程 hash 包含不可变正文，交付状态独立记录；Bootstrap 成功且模型验证通过才允许首任务。模型 seed 是提案，不能充当 Runtime 探针结果。

本轮使用结构化克隆事务验证合同原子性，没有 DB 事务、进程持久化、文件系统 worktree 操作或真实 Harness 能力。UI 消费只读夹具/类型；W11 必须以本合同实现真实 Core 并补齐相关测试。
