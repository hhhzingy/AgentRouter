# ADR 0001：核心架构与不可变语义

状态：已选择，2026-09-09。输入为原始 V1.0 开发包。

采用 pnpm 单仓库（monorepo）、Electron/React 桌面、独立 Node Core、better-sqlite3 单写者与版本化迁移。Domain 不依赖 UI 或 Harness。现有开发包保持原样，应用规范副本由哈希检查防止漂移。

发信持久化成功仅返回最小技术响应，无业务回执；完成仅按显式目标投递。finish 原子保存结果及 HELD outbox，经过真实 RunSettled、审批与写资源核对后方可释放。关联结果由 Core 根据已保存父子关系续办，同角色独立任务 FIFO。未知执行不自动重试，旧 epoch 不得影响现态。

Codex 使用 App Server，Kimi 使用协商 ACP，pi 使用 RPC 与自有扩展。模拟器明确标记 mock，不计入三家正式支持。native end 不能直接视为业务完成或验收。

认证单元（AuthUnit）默认串行；不读取、复制或覆盖当前用户凭据来完成离线开发。账号切换必须保存最新刷新文件、确认受控进程停止并核验实际身份。

内部桥仅暴露六个 Route 工具，凭据绑定受控身份。管理操作只走桌面 IPC；不开放外部管理或任意 API 代理。
