# J2 未实测与已知限制

- 真实账号、真实 Harness、真实 SSH/Linux 联调按用户约束未执行；SIMULATED_PROCESS 只验证可靠性，真实 Harness 支持仍为 0。
- 原生目录/保存对话框仅测试 Main 受控返回，OS 人工操作与五分钟可用性试用未观察。中文输入法采用真实 Electron composition 事件测试，未人工操作 Windows 候选窗。
- 冻结 conversation.read 按升序游标提供数据；界面明确从最早记录开始，未伪称默认最新。Role Charter 历史合同未提供尾页游标参数，has_more 时提示未完整。
- 本机草稿与待核对正文保存在 Electron 本机浏览器存储，不提供操作系统级秘密隔离认证；逐项清理不取消远端任务。诊断元数据不含正文，单独展开内容属于用户显式查看。
- Seed 模型可保存配置但不认证可用；初始化与保存独立。内部 AI 设置会话、真实账号切换、生产组重构及真实 worktree 仍禁用。
- 当前刷新使用250ms事件合并后的全快照以及30秒低频核对；不会每条事件读取账号和历史。超大项目的增量投影性能不在本轮认证范围。
- 工作区读写权限继续遵循当前 Core 的保守上限，不以界面选择扩大已授予权限。原 main 与 ui-baseline-v1 标签不变。
