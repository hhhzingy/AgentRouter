# 执行断点与下一会话入口

工作包 / 子任务 ID：待填。当前分支与 HEAD：待填。当前状态：PLANNED。

## 当前事实

记录当前工作树是否干净、哪些文件是用户/其他 worker 的修改、当前 lease owner、已合并与未合并的任务。写清已经做过的真实账号/SSH/进程动作，不包含秘密。

## 已通过与未通过

按 Test ID、source SHA、环境与证据列出；失败、BLOCKED_ENV、NOT_RUN 独立保留。不得直接沿用前一会话的口头“成功”。

## 当前外部状态

记录受控 Core/Run/任务/认证单元的非秘密身份，用户授权是否仍有效，是否存在 UNKNOWN/待审批/写资源隔离。重新连接前先核对，不能把未收到响应的命令重复发送为新 operation_id。

## 下一动作

写明一个明确可执行的下一步、允许路径、所需用户动作和停止条件。无网页复核依赖；用户阻断只影响相关步骤，独立离线任务可继续。
