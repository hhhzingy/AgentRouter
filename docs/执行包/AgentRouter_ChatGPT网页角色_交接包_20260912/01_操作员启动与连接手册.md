# 操作员手册:启动与连接(人执行,非 ChatGPT)

## 通道划分(重要)

| 场景 | 通道 | 说明 |
|---|---|---|
| 手机 / tailnet 内浏览器看只读控制台 | Tailscale Serve → Web Console(127.0.0.1:8787) | 只读,无写工具 |
| **网页 ChatGPT 参与角色** | **官方 Secure MCP Tunnel**(ChatGPT 桌面/连接器建立隧道到本机 participant MCP) | 3 个参与工具,可写 |
| 桌面远端 SSH | OpenSSH + ssh-bridge | 待 sshd 补装 |

**Tailscale Serve 不用于 ChatGPT 云端连接**——ChatGPT 云到本机走官方 Secure MCP Tunnel。

## 启动参与者入口

1. 确认 Core 运行中(`.local/management-live/core/endpoint.json` 存在);
2. 在 integration 目录启动 stdio 入口(Secure MCP Tunnel 由 ChatGPT 侧拉起本进程):
```
set AGENTROUTER_MANAGED_ROLE=1
node apps/participant-mcp/main.mjs .local/management-live/core <角色ID>
```
   或 HTTP 入口(本机回环,供隧道转发):
```
node --experimental-strip-types apps/participant-mcp/http.mjs .local/management-live/core <角色ID> --gen-token --port 8790
```
   token 按角色隔离存放:`participant-token-<角色ID>.txt`;泄漏即删除重建。

## ChatGPT 侧(在网页 ChatGPT 中执行)

1. 设置 → 连接器/Connectors → 添加自定义 MCP;
2. 连接方式选 **Secure MCP Tunnel**(需要 ChatGPT 桌面端配合建立本地隧道;纯网页入口如无该能力,见下方 BLOCKED_BY_HOST);
3. 指向本机 participant 入口(stdio 命令或隧道 URL + Bearer token);
4. 工具清单应恰好 3 个:`participant_read_inbox` / `participant_send_user_input` / `participant_register_artifact`;
5. 按 `00_给网页ChatGPT的执行说明.md` 执行闭环。

## BLOCKED_BY_HOST 判定

出现以下任一情况,该真实宿主用例标 `BLOCKED_BY_HOST`,不绕过、不阻塞其他支线:
- 账号无连接器/MCP 或 Developer/write 权限;
- 纯网页入口无法建立 Secure MCP Tunnel;
- 隧道建立但工具清单缺失或连接器审核拒绝。

## 验收闭环

操作员给已审核文本 → ChatGPT 调 `participant_register_artifact` → 回报 `artifact_id`+`sha256` → 操作员本地核对工作区文件与 DB `artifacts` 行 → PASS。

## 停止与轮换

- Ctrl-C 停入口;关闭隧道;
- token 轮换:删除 `participant-token-<角色ID>.txt` 后 `--gen-token` 重启;
- 新会话挂接即 generation 递增,旧会话写权限自动失效(PARTICIPANT_GENERATION_STALE)。
