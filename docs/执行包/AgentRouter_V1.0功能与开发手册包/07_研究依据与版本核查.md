# AgentRouter V1.0 研究依据与版本核查

核查日期：2026-09-09。仅使用官方规范、官方文档和项目源码作为技术依据。研究不等于真实 Windows、账号、打包或兼容测试。

## 1. 最重要的本轮结论

pi 采用独立 RPC 与扩展，不假定原生 MCP／ACP；agent_settled 与 agent_end 的差别影响队列放行。SQLite 实际运行库需包含 WAL-reset 修复。Codex 的静态种子凭据不可反复覆盖最新刷新文件。Kimi 的 HTTP 成功不保证额度查询业务成功。

## 3. 实施时必须补齐的证据

每项能力记录可执行文件路径、哈希、版本、原生握手与 Schema、测试用例、测试日期、脱敏结果与状态。main 分支链接是可变资料，实施冻结时补充对应提交或发布版本。文档读取日期不能填写为真实联调通过日期。

## 4. 证据等级

RESEARCHED 表示官方资料支持；PROBED 表示本机只读探测；CONTRACT_TESTED 表示固定样本验证；LIVE_TESTED 表示真实 Harness 联调；PACKAGED_TESTED 表示发布环境验证。只有满足对应 Gate 才能标支持。当前文件包不声称任何真实 Harness 已达到 LIVE_TESTED。
