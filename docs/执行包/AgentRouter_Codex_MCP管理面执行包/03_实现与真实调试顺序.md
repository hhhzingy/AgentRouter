# 实现顺序

## M0 Management façade
- 新建 management-gateway / management-mcp
- 使用现有Client API
- audit origin=MCP
- observer/controller
- 不修改RoleBridge成万能桥

## M1 STDIO MCP
- 使用稳定MCP TypeScript SDK并锁定实际版本
- stdout只输出协议；诊断stderr脱敏
- Core不存在明确失败，不偷偷切Fixture
- MCP退出不结束Core或已派任务
- capability驱动工具

## M2 读面
status/project/role/task/result/conversation/models/issues/events；严格scope和分页。

## M3 写面
controller lease + request_key；Role Plan、dispatch、cancel、result。

## M4 当前开发Codex实际接入
首轮使用真实LOCAL_CORE/SQLite，但不需要真实Harness：
1 status
2 project/role读取
3 validate小Role Plan
4 acquire control
5 apply到专用MCP smoke project
6 重启MCP
7 确认数据持久
8 release

Codex配置不要提交仓库，不放任何Secret到MCP env。

## M5 API Registry
先本地mock/HTTPS Action，再实际已登记API。
