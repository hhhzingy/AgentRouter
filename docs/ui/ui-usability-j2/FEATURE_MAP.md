# J2 功能落点

| 功能 | 入口及处理 |
|---|---|
| 项目卡/创建 | 首页；保留原生目录授权桥，三组五头像与独立角色链接 |
| 概览/协作组 | 工作台；小组管理保留重构说明，生产禁用 |
| 时间线 | 动态；按项目/组/角色作用域分页 |
| 收件箱/产物 | 成果 → 交付给我 / 文件与报告；验收、校验和保存能力门控 |
| 审批/问题/UNKNOWN | 项目头待处理与角色危险面板持续可达 |
| 角色对话 | 角色页主区；工具折叠、GAP、失败重试、分页、统一任务输入 |
| Role Charter | 角色设置 → 说明与原始修订；历史查询 has_more 时明确范围限制 |
| Role Plan | 添加角色 → 手工、JSON 文件/粘贴、外部 AI 规划指南；内部 AI 设置会话未实现禁用 |
| 模型/账号 | 设置 → 运行环境；来源、档位、未验证状态、脱敏 Profile 保留；真实账号切换禁用 |
| 权限/工作区 | 角色设置；依据精确 project/workspace ID 和已授予 Charter |
| 草稿/待核对 | 独立本机存储；全局待核对面板；项目设置逐项查看/清理未知旧记录与备份 |
| 连接/诊断 | 顶部连接状态与帮助；断线健康未知、只读；不承诺远端运行 |

旧 overview/spaces/timeline/inbox/issues/artifacts/models/settings 路由保留；四主导航按目的归并。原型重构流程保留但生产入口不开放，未来 W11B 完善安全闭环。没有新增 Core、全量合同或数据库迁移。
