# 02 首页项目卡

## 一、定位

项目卡是**状态摘要**，不是管理页。一屏之内回答四个问题：

1. 这个项目在哪（Local/SSH、主机、路径）；
2. 里面有几个协作组、谁在里面；
3. 现在需不需要我（待介入/待审批/UNKNOWN）；
4. 最近在动吗（活跃 Run、最近活动）。

点击进入项目页。卡片不提供行内写操作（不停靠按钮、不内嵌表单）。

## 二、卡片结构（标准尺寸 360×220，响应式）

```text
┌────────────────────────────────────────┐
│ 支付中台重构                   ⌁ SSH    │  ← 项目名 + 连接徽标(Local/SSH)
│ core-prod-01 · ~/work/pay…             │  ← Core 主机 + 路径简写
│────────────────────────────────────────│
│ 核心实现组        ●林  ●周  ◐陈        │  ← 组行：组名 + 角色头像(≤5)
│ UI 组             !苏  ○唐  +2         │  ← 超出 +N
│ +1 个组                                │
│────────────────────────────────────────│
│ ▶2 运行  ⚠1 介入  ⏸1 审批  ⧉3 排队     │  ← 聚合计数条
│ 刚刚 · 周实现 提交了「登录接口」        │  ← 最近活动一行
└────────────────────────────────────────┘
```

| 区域 | 内容规则 |
|---|---|
| 标题行 | 项目名（单行截断）；Local/SSH 徽标带图标+文字，不只靠颜色 |
| 位置行 | `hostLabel` + `displayRoot` 简写（中间省略，hover 全路径 Tooltip） |
| 组概览 | 最多 3 组；每组：组名 + 最多 5 个角色头像方块；头像内含展示名缩写（2 字）+ 状态角标；超出组 `+N 个组`，超出角色 `+N` |
| 计数条 | 活跃 Run / 待介入 / 待审批 / 排队四项，为零的项不渲染 |
| 最近活动 | 相对时间 + 角色名 + 一行摘要；无活动显示"暂无最近活动" |

数据来源：C1 `ProjectVM` 只有聚合计数（`spacesCount/activeRunsCount/issuesCount`），组行与角色头像、最近活动需要 CCR-UI-01（项目卡摘要 VM）与 CCR-UI-12（最近活动）。Phase A fixtures 以 `x_proposal` 标注演示。

## 三、角色头像角标（与 07 状态系统一致）

| 角标 | 含义 | 优先级 |
|---|---|---|
| `!` | 需用户介入 / 等待审批 | 最高 |
| `?` | UNKNOWN / 恢复核对 | 高 |
| `●` | 正在执行 / 正在收尾 | 中 |
| `◐` | 等待输入 / 下属结果、有排队 | 低 |
| `○` | 空闲 | 最低 |
| `⏸` | 已暂停 | 覆盖性状态 |
| `✓` | 最近完成（短时次要标记，不覆盖上述） | 仅辅助 |

头像本身 = 色块 + 名缩写，色块由 role_id 哈希到 8 色调色板，保证同一角色全应用同色。

## 四、八种卡片状态

### 1. 无项目（空首页）

```text
┌───────────────────────────────────────────────┐
│                                               │
│        还没有项目。                            │
│        从一个文件夹开始，让角色在其中协作。      │
│                                               │
│        [ ＋ 创建新项目 ]                       │
│                                               │
└───────────────────────────────────────────────┘
```

网格中只剩创建卡，居中放大展示引导文案（见 01 §十二）。

### 2. 1 个项目 1 个组

组概览只有一行组；计数条按实际渲染。新建项目默认形态。

### 3. 1 个项目 2 个并行组

两行组概览。两组各自带工作区标注（`wt:core` / `wt:ui`），并行写场景在组名后加 `⧉worktree` 小标，强化"组 ≠ worktree"认知。

### 4. 多项目

网格按"最近活动"倒序排列；项目数 >12 时启用虚拟滚动，不按组分页。搜索框过滤项目名/主机。

### 5. Local / SSH

- Local：`⌂ Local · 本机`；
- SSH：`⌁ SSH · core-prod-01`；连接非 CONNECTED 时位置行叠加连接状态（重连中/已降级/已断开），断开的项目卡整体降饱和但**数据保持可见**（Core 继续运行，见 sc-25）。

### 6. 角色执行/等待/需介入/空闲混合

同一张卡内四种角标并存（§三表）。**需介入与待审批不仅上角标，还累计到计数条**，保证小屏只看计数条也不漏。

### 7. 创建项目卡（与项目卡同尺寸）

```text
┌────────────────────────────────────────┐
│                                        │
│              ＋                        │
│         创建新项目                      │
│   选择 Core 与目录，30 秒完成           │
│                                        │
└────────────────────────────────────────┘
```

永远排在网格最后一位；点击进 `/projects/new` 向导（01 §四）。卡内不堆表单字段。

### 8. 小屏与高 DPI

| 断点 | 行为 |
|---|---|
| ≥1440px | 4 列 |
| 1080~1439 | 3 列 |
| 720~1079 | 2 列 |
| <720 | 1 列，组概览从 3 组降为 2 组 + `+N` |
| 缩放 125%/150% | 列数按有效宽度自动降档；头像/角标矢量绘制不模糊；最小触控 28px |
| 高 DPI | 全部图标 SVG/字体，无位图资源 |

## 五、可访问性

- 每张卡是一个 `<article>`，组行有 `aria-label="协作组：核心实现组，3 个角色"`；
- 角标配 `role="img"` + 文本等效（Tooltip 与 sr-only 文本双通道）；
- 键盘：Tab 在卡间移动，Enter 进入项目，`+N` 可聚焦展开完整列表（弹层）；
- 状态不只靠颜色：图标 + 文字计数 + Tooltip 三通道（07 §十）。
