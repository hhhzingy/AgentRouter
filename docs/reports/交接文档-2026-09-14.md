## 1. 本轮(R3—R6)做了什么

### R3 — DeepSeek 生产闭环(提交 `46e0df2`)
问题链:bootstrap FAILED → 定位为三处叠加缺陷,逐一修复后连续两次 PASS。
1. `packages/platform/local-native-runtime.ts`:dsh 分支的 `saveSession` 被硬编码为
   `DSH_SESSION_SAVE_UNSUPPORTED`,而 backend 在 open 后必调 saveSession → bootstrap 必败。
   改为与 kimi 相同的真实落库(按 RoleSession 镜像)。
2. `packages/client-contract/c1r1p2.ts` 的 `widen()`:只放宽 `enum` 形态,而冻结 client-api schema 的
   harness 枚举是 `anyOf:[{const:'codex'},{const:'kimi_code'},{const:'pi'}]` 形态 → P2 客户端结果校验
   实际从未放宽,role.list 返回 `deepseek_harness` 即 INVALID_FRAME。现两种形态都放宽为
   `type:string + pattern ^[a-z][a-z0-9_]{1,40}$`。
3. `packages/client-contract/c1r1p1/index.ts`:`validateFrame/validateDefinition` 对 `C1R1P2` 连接
   委托放宽校验器(原先落回 P1 schema)。
4. `packages/core-service/application.ts`:旧协议连接的投影裁剪从"只裁 snapshot.roles"扩展到
   snapshot.roles + snapshot.runs + role.list + run.list(动态 harness 角色及其运行对冻结客户端不可见)。
5. `packages/core-service/harness-drivers.ts` dshDriver.runPrompt:resume 会话里残留 bootstrap 的
   "回复 ACK 一次"指令,deepseek-v4-flash 会复读 ACK 而不执行任务;任务轮 prompt 显式作废该指令并
   重申章程与工具用法。`native-process-backend.ts` 接入可选 `driver.runPrompt` 钩子。

### R4 — 原生 A/B 会话隔离 + 交接包 ACK + GUI(提交 `3a6354e`)

- `packages/core-service/native-session-store.ts`:load/save 按可选 `roleSessionId` 键控——
  有会话自身引用读自身;**仅初始会话(seq 最小)无引用时继承 binding 级(bootstrap 建的)会话**;
  create/switch 出的新会话无引用即全新(`undefined`),不得续用他人上下文。
- dispatch 链贯通:coordinator → backend → host → prepare 传递 `roleSessionId`。
- `dshDriver.supportsFreshSession=true`:无预载引用允许 `session/new`(backend 的
  NATIVE_SESSION_REQUIRED 强校验改为仅对无此能力的驱动生效;pi 仍要求会话文件)。
- 交接包流:`RoleSessionExtension.create/switch` 时导出来源会话快照(openTasks+最近20条对话+章程hash);
  目标会话首运行 prompt 前置交接包+ACK 指令(`AGENTROUTER_HANDOFF_ACK:<hash>`),ACK 出现前 Route 工具
  一律 `HANDOFF_ACK_REQUIRED`;ACK 文本经 `handoff_ack` 帧推进 handoffs 行为 ACKED(coordinator 分支)。
- GUI:`workbench/store.tsx` 新增 `callExtension`(roleSession.* 不经冻结 capability 清单与操作账本);
  `workbench/pages-role.tsx` 新增 SessionWorkflow 卡(列表/新建并切换/切回/观察者只读降级)。
- **真实验收**(`tools/test-j3-production-pi.mjs --live --dsh --ab`):A→B→A→C 三会话,3 交接包全
