## 4. 关键语义决定（供复核确认）

1. **空 scope = 不给未声明权限**（W06）；受限连接 `project.create` 的自创建项目仅对自己可见（不越权）。
2. **历史 WorkSession 永久只读**：activate/切回历史 WS 一律拒绝（`ROLE_SESSION_REACTIVATION_REMOVED`）；保留当前 ACTIVE 原生续轮、completion.mode=handoff、可读历史（conversation_items）。4 个旧语义测试已替换为负例（映射表见 W10 报告），未为保数而留。
3. **一次性 Context Transfer**：导出→容量决定（T≥S/A≤T/A>T/UNKNOWN=ASK_USER）→源压缩一次→目标盲建新会话；journal 015 可审计；失败不半状态。
4. **ZCode 0.16.5 续轮降级**：冷 resume 后模型客户端不可恢复为官方实测（-32031），驱动改为一律新会话+runPrompt 重申章程，能力如实 `native_resume=UNSUPPORTED`——不伪造续轮。
5. **迁移纪律**：001—013 字节冻结不动，只加 014/015。
6. **打包**：LOCAL_CORE 默认；REMOTE_CORE 由 env opt-in（同一芯）；第二机同一包以 `AGENTROUTER_MODE=REMOTE_CORE` 启动即为远程客户端。

## 5. 安全边界执行记录

- 任何 key/token/配对码不打印、不提交、不贴聊天；凭据文件只在受信宿主读取；标签格式 base_url/api_key/model 由专用解析器处理。
- 手机 token 仅 HttpOnly Secure SameSite=Strict cookie；桌面 body+cookie 双载体；renderer 永不经手 token（Main safeStorage）。
- 生产 Codex/ZCode 桌面登录未被触碰；DUT 全部独立受管 HOME；账号切换不在本包。
- 1M 压缩实测按指示挂起（工具与口径保留，不计入本轮分母）。
